# Code of Conduct

Dieses Projekt verwendet den [Contributor Covenant, Version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Von allen Beteiligten wird ein respektvoller, sachlicher und inklusiver Umgang erwartet. Belästigung, persönliche Angriffe und die Veröffentlichung privater Daten werden nicht akzeptiert. Verstöße können über GitHubs private Kontaktmöglichkeiten an die Repository-Verantwortlichen gemeldet werden.
