# Contributing

Vielen Dank für dein Interesse. Das wichtigste Projektmerkmal ist die technisch erzwungene Read-only-Grenze.

## Änderungen vorbereiten

1. Keine echten Telefonnummern, PINs, Codes, Cookies, Kontostände oder Depotdaten in Code, Tests, Issues oder Logs einfügen.
2. Keine mutierenden Trade-Republic-Endpunkte, freien URLs oder frei wählbaren WebSocket-Topics hinzufügen.
3. Abhängigkeiten exakt pinnen und Installationsskripte deaktiviert lassen.
4. Für geändertes Verhalten aussagekräftige Tests ergänzen.
5. Vor einem Pull Request `npm run check` und `npm audit signatures` ausführen.

Sicherheitsprobleme bitte über GitHubs private Vulnerability-Reporting-Funktion melden und nicht als öffentliches Issue veröffentlichen.
